# Spiderling

**Spiderling** is a parallel web scraping framework written in Clojure.

It allows users to submit lists of URLs to scrape and processes them concurrently, providing a RESTful API to monitor progress, retrieve results, and manage scraping jobs.

Spiderling is designed to showcase:

- **Parallelism and concurrency** in Clojure
- **Data validation** using spec/malli
- **REST API design** with modern Clojure libraries

This project serves as a foundation for building scalable, concurrent web scraping services in Clojure.
